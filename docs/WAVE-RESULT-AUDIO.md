# Wave result sounds

Victory uses a 3.92-second orchestral fanfare; defeat uses a contrasting 3.18-second cue. Both are local Ogg Vorbis assets (about 129 KiB combined), loaded alongside the original audio. Combat's existing terminal events play each cue once; opening the result screen again does not replay it. Result cues use the effects bus, effects volume and master mute. They have priority over the combat voice limit. Music drops on results and restores on leaving results. The original achievement gong remains unchanged.
